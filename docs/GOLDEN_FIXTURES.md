# 黄金夹具与真实工程验收

公开仓库只包含人工构造的最小 `.epro2`、`.enet`、BOM、PDF 和协议夹具。它们用于验证解析规则、安全限额、稳定错误码、确定性哈希和 MCP 行为，不包含真实产品工程。

真实工程只允许作为开发者本机的私有验收输入：

- 不进入 Git、npm 包、CI Artifact 或 Issue；
- 绑定文件只保存于 Git 忽略目录；
- 公开结果只保留匿名计数、稳定原因码和工具版本；
- 更新黄金清单必须人工审查确定性差异；
- 黄金回归通过不等于来源真实性或完整电气真值通过。

公开验证命令：

```bash
npm run check
npm test
```

真实工程验收由维护者在本机执行，并且只把通过/失败、匿名计数和稳定原因码带入发布评审。任何单个工程通过都不能代表所有嘉立创 EDA 工程格式已被完整覆盖。
