# 黄金夹具与真实工程验收

公开仓库只包含人工构造的最小 `.epro2`、`.enet`、BOM、PDF 和协议夹具。它们用于验证解析规则、安全限额、稳定错误码、确定性哈希和 MCP 行为，不包含真实产品工程。

真实工程只允许作为开发者本机的私有验收输入：

- 不进入 Git、npm 包、CI Artifact 或 Issue；
- 绑定文件只保存于 Git 忽略目录；
- 公开结果只保留匿名计数、稳定原因码和工具版本；
- 更新黄金清单必须人工审查确定性差异；
- 黄金回归通过不等于来源真实性或完整电气真值通过。

公开验证命令：

```bash
npm run check
npm test
```

维护者可以通过仓库外私有清单运行真实工程门禁：

```bash
SCHEMCP_REAL_PROJECT_MANIFEST=/绝对路径/私有清单.json npm run verify:real-projects
```

清单必须冻结每个匿名样本的 `.epro2`/`.enet` 哈希、诊断基线和网表差异上限；层级、BUS 或装配特征样本还应冻结对应计数。验证器不会扫描目录，也不会自动接受新基线。它会连续编译真实工程以复验确定性，使用隔离 npm 缓存生成候选包，在全新目录离线安装，并通过 stdio 执行 `initialize`、`tools/list` 和真实层级/BUS 工具调用。

完整回执默认写在私有清单同目录，只含样本编号、哈希、计数和状态；stdout 不回显路径、UUID、网络名或位号。真实工程验收由维护者在本机执行，并且只把通过/失败、匿名计数和稳定原因码带入发布评审。任何单个工程通过都不能代表所有嘉立创 EDA 工程格式已被完整覆盖。
